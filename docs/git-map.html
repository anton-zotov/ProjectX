Как это читать (и что будет дальше)

Что уже произошло

Первые три коммита — общие: они и в main, и в playground. От последнего из них (124c0bb, 15.09) playground и отпочковался — на схеме это пунктирная линия. Дальше зелёная линия живёт своей жизнью: там вся работа по физике.

Сегодня main догнал нас: в него положена та сборка, которая сейчас работает лучше всех. С этого момента «пляшем» от main.

Что будет с ветками

Ничего не удаляется. Коммиты, которые оказались неудачными, остаются в истории навсегда — они просто не лежат на линии main. Это нормально: история показывает, что мы пробовали.

Продвижение в main. Когда очередное состояние тебе нравится, я «продвигаю» его: main получает новый коммит, и его линия уходит вниз. Ветка playground при этом не «сливается» и не обрывается — она продолжает жить своей линией.

Параллельные темы. Да, для этого ветки и нужны. Схема, когда git будет стоять: от main отпочковывается physics и visuals, каждая делает своё, потом обе вливаются обратно. Пока git не поставлен, я кладу в репозиторий снимок всего дерева, а не отдельные изменения, — поэтому объединять две ветки мне пришлось бы вручную. Пока так: одна тема за раз, в playground.

Схема работы, как она будет выглядеть с git
