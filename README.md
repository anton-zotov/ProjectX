# ProjectX

Мини-игра на canvas: надпись **Hello, World!**, которой управляют стрелками,
летает по большому игровому полю на фоне самосветящейся псевдо-3D решётки.

## Запуск

Для разработки (горячая перезагрузка):

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

## Проверки и релиз

Тесты и проверка типов — отдельные команды: **во время игры они не выполняются**
и на неё не влияют. Запускайте их перед релизом:

```bash
npm run preflight  # typecheck + тесты + production-сборка
npm test           # только автотесты (34 штуки, без внешних зависимостей)
npm run typecheck  # только проверка типов
```

Поиграть в собранную версию (легче для машины: без dev-сервера, вотчера и HMR):

```bash
npm run build
npm run serve      # отдаёт dist/ на http://127.0.0.1:5173
```

## Что внутри

- **Поле** — 3×2 экрана (960×360), камера свободно следует за надписью и может
  заглядывать за края карты; за границей зоны — «стена» (лист с прямоугольной
  дыркой), сквозь которую видно трёхмерное пространство.
- **3D-пространство** — уровни глубины (поперечные линии) плюс «лучи»,
  уходящие вдаль; яркость и толщина зависят от глубины, совпадающие линии
  не складываются в сверхъяркие, лучи плавно появляются/гаснут у края экрана.
- **Цвета** — переливаются сами (две дрейфующие синусоиды), скорость
  регулируется.
- **Админка** — кнопка ⚙ справа сверху: скорость движения, авто-движение,
  скорость цвета, размер поля, размер ячейки фона, вкл/выкл 3D-сетки и
  сглаживание 2× (снять его — самый быстрый способ поднять FPS: буфер
  становится 1×, то есть растеризация вчетверо дешевле).
  После правки фокус возвращается в игру, чтобы стрелки сразу управляли надписью.
- **FPS** — счётчик в левом верхнем углу: `fps 60  16.7 ms` (ограничен частотой
  обновления монитора: на 60 Гц больше 60 не покажет). Галочка
  «профилирование» добавляет строку `upd X ms · draw Y ms`, чтобы понять, что
  именно стоит кадров — логика или отрисовка.

## Структура

```
src/
  main.ts               точка входа + админка (DOM)
  engine.ts             цикл кадров, canvas, масштабирование (буфер 2x)
  scene.ts              интерфейсы Scene / GameContext
  input.ts              состояние клавиатуры (isDown / axis)
  scenes/helloWorld.ts  игровая сцена: физика, камера, отрисовка
tests/
  helpers.mjs           подставные canvas/DOM, чтение нарисованного
  loader.mjs            ESM-хук: расширения + заглушка для .css
  scene.test.mjs        логика поля, камеры, настроек, сетки, цвета, fps
  input.test.mjs        клавиатура
  app.test.mjs          движок (кадры, ресайз, dt) + админка
versions/               локальные снапшоты версий (см. versions/README.md)
```

## Тесты

Тесты используют встроенный раннер Node и импортируют TypeScript напрямую
(Node стирает типы, `tests/loader.mjs` добавляет расширения) — никаких
тест-фреймворков и сборки. Отрисовка проверяется через подставной
canvas-контекст, который записывает все вызовы.
